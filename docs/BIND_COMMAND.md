# `/bind` QQ OpenID 获取指令

## 背景

用户需要将 QQ 账号与 LumiAdmin 网站账号绑定，才能接收基于 QQ 的通知。
`/bind` 让用户在 QQ 私聊机器人即可获取自己的 OpenID，无需管理员人工收集。

## 用法

用户在 QQ 私聊机器人发送：

```text
/bind
```

机器人回复：

```text
你的 QQ OpenID：

1234567890xxxxxxxx

请复制此 OpenID 到 LumiAdmin 网站的 QQ 绑定页面完成绑定。
```

用户复制 OpenID 后在网站的 QQ 绑定页面填写即可自助完成绑定
（管理员也可用该 OpenID 在后台代用户绑定）。

## 使用规则

- 只处理 QQ C2C 私聊消息；群聊、频道中发送 `/bind` **不回复**（指令被静默忽略，避免公开场景暴露 OpenID）；
- 只支持精确指令 `/bind`，不接受参数和别名（忽略首尾空白，大小写不敏感）；
- 所有 QQ 用户均可使用；
- OpenID 直接取自 QQ 私聊事件的消息发送者 ID（即 C2C openid）；
- 每个用户每分钟最多使用 5 次（窗口滑动，超出后回复“请求过于频繁，请稍后再试。”）；
- 用户可以重复执行，OpenID 不会变化；
- OpenID 冲突由管理员在网站绑定时人工处理，本次不自动查询或修改 LumiAdmin 用户信息。

无法获取 OpenID 时仅记录日志，不回复（避免向非法目标发送信息）。
